# Mensagens verbatim (raw)

> **Nada se perde.** Toda mensagem do cliente/implantador que traga pedido,
> dado, decisão ou direcionamento é salva aqui **exatamente como veio**.

- Nome: `AAAA-MM-DD-NN-assunto.md` (NN = sequência do dia; assunto curto, sem acento).
- Conteúdo:

```
# AAAA-MM-DD-NN — <assunto>
> **De:** <papel (dono/implantador/…)> · **Canal:** chat da sessão / e-mail / áudio transcrito
> **Recebida em:** AAAA-MM-DD HH:MM (America/Sao_Paulo) · **Sprint:** Sxx

<texto literal, sem corrigir nada>

---
**Encaminhamento:** decisão → decisoes/DECISOES.md · direcionamento → diretrizes-da-equipe.md · dado → dados/… · lacuna → pendencias/LACUNAS.md
```

- **LGPD:** se a mensagem tiver dado de paciente, substitua por `[dado de paciente omitido]`
  e diga isso ao usuário.
